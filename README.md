# hola-mundo-daw
Este es un repositorio de prueba para la asignatura de Despliegue de aplicaciones web. 
Soy un alumno de 2DAW, y en este curso vamos a aprender tecnologías como JavaScript, PHP o Python.
Además aprenderemos herramientas como GitHub para despliegue de aplicaciones y nuevos IDE
con los que trabajar.

Por último también vamos a aprender a diseñar páginas web, así reforzando los conocimientos en
tecnologías de etiquetación HTML y CSS.
